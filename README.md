# DAA-PRACTICALS

Practical - 01

Summary : Sorting is a technique used to organize data in ascending or descending order. Bubble Sort exchanges adjacent elements, Selection Sort places the smallest element in its correct position, and Insertion Sort inserts elements into their proper places. Merge Sort and Quick Sort use divide-and-conquer techniques to improve sorting efficiency.

Conclusion : Different sorting algorithms have different performance levels and implementation methods. Simple algorithms are suitable for smaller datasets, while Merge Sort and Quick Sort are often preferred for larger datasets because of their better efficiency.

Practical - 02

Summary : Linear Search finds an element by checking each item in sequence until the target is located. Binary Search works on sorted data by repeatedly dividing the search range into two halves and continuing with the relevant half.

Conclusion : Linear Search is easy to implement and supports sorted as well as unsorted data. Binary Search offers faster searching for sorted datasets, making it more suitable for large collections of elements.

Practical - 03

Summary : Heap Sort is a sorting algorithm that organizes elements using a Max Heap structure. It repeatedly extracts the largest element and places it in its correct position to produce the final sorted sequence in ascending order.

Conclusion : The Heap Sort algorithm was implemented successfully to sort the given data. With a time complexity of \(O(n\log n)\) and low additional memory requirements, it provides an efficient approach to sorting.

Practical - 04

Summary : The factorial of a number was computed using both iterative and recursive techniques. The iterative method uses repetition, whereas the recursive method solves the problem by calling the same function with a smaller input.

Conclusion : Both approaches calculate the factorial correctly and have a time complexity of \(O(n)\). The iterative method generally consumes less memory, while the recursive method provides a simple and mathematical way to represent the solution.

Practical - 05

Summary : The Knapsack Problem can be solved using Dynamic Programming by considering smaller subproblems and storing their solutions. This approach helps select items that provide the highest possible value without exceeding the given weight capacity.

Conclusion : Dynamic Programming helps find the optimal solution to the Knapsack Problem by storing intermediate results and preventing repeated calculations. It ensures that the maximum possible value is obtained within the specified capacity.

Practical - 06

Summary : Matrix Chain Multiplication uses Dynamic Programming to determine the best sequence for multiplying multiple matrices. It evaluates smaller matrix chains and uses their results to find the order requiring the fewest scalar multiplications.

Conclusion : The Dynamic Programming approach identifies an efficient multiplication sequence and reduces the total number of operations. This improves computational efficiency without changing the final matrix product.

Practical - 07
Summary : The Making Change Problem uses Dynamic Programming to calculate the minimum number of coins required to form a given amount. Results for smaller amounts are stored and reused to solve the larger problem efficiently.

Conclusion : Dynamic Programming provides an effective method for solving the Making Change Problem. It reduces repeated calculations and helps determine the minimum number of coins needed to reach the target amount.

Practical - 08

Summary : Graph traversal involves visiting the vertices of a graph systematically. Breadth-First Search (BFS) explores vertices level by level using a queue, while Depth-First Search (DFS) follows a path as deeply as possible using recursion or a stack.

Conclusion : BFS and DFS are essential techniques for exploring graphs. BFS is useful for finding shortest paths in unweighted graphs, whereas DFS is helpful for identifying connected components and exploring graph structures.

Practical - 09

Summary : Prim’s Algorithm is a greedy technique that constructs a Minimum Spanning Tree (MST) by starting from one vertex and repeatedly adding the minimum-weight edge that connects the current tree to a new vertex.

Conclusion : Prim’s Algorithm connects all vertices of a connected, weighted graph with the minimum total edge weight. It is particularly useful in network design and other problems where minimizing connection costs is important.

Practical - 10

Summary : Kruskal’s Algorithm finds a Minimum Spanning Tree by sorting graph edges according to their weights and selecting the lowest-weight edges that do not form cycles. The implementation uses the Union-Find data structure to manage connected components efficiently.

Conclusion : Kruskal’s Algorithm was successfully implemented in Python, producing a Minimum Spanning Tree with a total cost of 19. It demonstrates how a greedy approach can connect all vertices while minimizing the overall edge weight.
